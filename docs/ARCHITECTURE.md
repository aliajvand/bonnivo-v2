# Bonyo / Bonnivo — Master Architecture

## 1. Directory Structure
- `apps/web/`: Next.js 15 App Router, Tailwind CSS, shadcn/ui primitives, Three.js 3D landing, RTL Persian UI.
- `apps/backend/`: FastAPI backend, Pydantic v2 schemas, PostgreSQL with SQLAlchemy 2.0.
- `apps/mobile/`: React Native (Expo) mobile application with NativeWind.
- `packages/api-client/`: Shared TypeScript types and API fetch wrapper.
- `icons/`: Logos, SVGs, and brand category image assets.
- `docs/`: Source of truth specifications for Phase 1.
